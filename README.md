# 🐯 多拼国 · 用拼音学自然拼读

给中文母语者的英语自然拼读（Phonics）学习工具：**用拼音近似记忆字母组合**，拼音里没有的音（th、v、æ 等）配合口型提示 + 发音跟读。

**在线使用**：`https://onekb.github.io/duopinguo/`

## 两个应用

| 文件 | 说明 |
|---|---|
| `phonics-game.html` | 🎮 **拼读大冒险**（多邻国式）：10 个单元 30 关冒险地图 + 特训中心（句子闯关 / 听写训练 / 音节与重音）+ 红心、连击、XP、每日连胜 |
| `phonics-pinyin.html` | 📚 **学习手册**：6 页签 —— 67 张组合卡片（拼音对照/口型提示/点读例词）、可解码句子、听写练习、多音节规则、随机练习、可打印速查表 |

`index.html` 是入口页。

## 学习内容

- ①-⑥ 核心规则：短元音、基础辅音、长元音（魔法 e）、辅音组合、r 控制元音、其他元音组合
- ⑦-⑨ 进阶：进阶 r 组合与长音拼法、无声字母与特殊读法、辅音连缀与词缀
- ⑩ 高频词 Sight Words：one ≈ 拼音 wan（万）、two ≈ tu（图）、who ≈ hu（呼）……

## 技术说明

- 纯静态单文件 HTML，无依赖、无构建、离线可用（双击即用）
- 发音：浏览器 Web Speech API（可选音色/语速）；音效：Web Audio 合成
- 进度存于浏览器 localStorage（冒险星星、特训星、XP、连胜）
